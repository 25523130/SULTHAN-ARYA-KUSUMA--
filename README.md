## Pertemuan 4 — Design token halaman profil

* Berkas gaya yang akan dibuat: `tokens.css`, `base.css`, `layout.css`, `komponen.css`, `tema.css`
* Warna utama: `#1D4ED8` (biru), dipilih karena memberikan tampilan yang sederhana, jelas, dan konsisten pada halaman profil.
* Design token digunakan agar perubahan warna dan ukuran dapat dilakukan secara terpusat dan mudah dirawat.

### Token yang saya tetapkan

| Token             | Nilai     | Untuk apa                        |
| ----------------- | --------- | -------------------------------- |
| `--color-primary` | `#1D4ED8` | tombol, tautan, penanda          |
| `--color-fg`      | `#0F172A` | warna teks utama                 |
| `--color-bg`      | `#F8FAFC` | latar halaman                    |
| `--color-surface` | `#FFFFFF` | latar kartu dan panel            |
| `--color-border`  | `#D1D5DB` | garis dan tepi                   |
| `--color-danger`  | `#B00020` | peringatan dan isian tidak valid |
| `--color-focus`   | `#2563EB` | garis fokus keyboard             |
| `--radius-md`     | `0.5rem`  | sudut tombol, kartu, dan input   |
| `--space-4`       | `1rem`    | jarak standar antar elemen       |
| `--text-md`       | `1rem`    | ukuran teks isi                  |

Kriteria selesai saya: mengubah `--color-primary` di satu baris harus mengubah warna tombol, tautan, judul, dan garis fokus.
