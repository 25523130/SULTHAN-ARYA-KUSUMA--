## Pertemuan 4 — Design token halaman profil

- Berkas gaya yang akan dibuat: `tokens.css`, `base.css`, `layout.css`, `komponen.css`, `tema.css`
- Warna utama: `#2563EB` (biru), dipilih karena memberikan tampilan yang jelas, sederhana, dan mudah digunakan sebagai warna utama untuk tombol dan tautan.
- Design token digunakan agar perubahan warna, jarak, ukuran, dan komponen dapat dilakukan secara terpusat dan mudah dirawat.

### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| `--color-primary` | `#2563EB` | tombol, tautan, dan penanda |
| `--color-fg` | `#1F2937` | warna teks utama |
| `--color-bg` | `#F5F7FA` | latar halaman |
| `--color-surface` | `#FFFFFF` | latar kartu dan panel |
| `--color-border` | `#CBD5E1` | garis dan tepi |
| `--color-danger` | `#DC2626` | peringatan dan isian tidak valid |
| `--color-focus` | `#F59E0B` | garis fokus keyboard |
| `--radius-md` | `0.75rem` | sudut tombol, kartu, dan input |
| `--space-4` | `1.25rem` | jarak standar antar elemen |
| `--text-md` | `1rem` | ukuran teks isi |

Kriteria selesai saya: perubahan warna utama pada token yang digunakan bersama harus dapat diterapkan ke elemen terkait seperti tombol dan tautan tanpa mengubah CSS komponen satu per satu.
